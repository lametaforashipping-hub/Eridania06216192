<analysis>**original_problem_statement:**
The user's overall goal is to build a comprehensive lottery management system for a Super Admin to oversee all operations in real-time.

Initial requests from the previous session included:
*   A detailed report for admins/sellers with ticket-by-ticket breakdowns.
*   A compact, readable, and bolded printed ticket design.
*   PDF export and sharing options (WhatsApp/Email) for reports.
*   A terminal identifier for each user/seller, with a dedicated search and list view.
*   An interface for paying out winning tickets.
*   Super Admin controls to edit winning percentages per prize tier and per lottery.
*   Allowing the selection of all available lotteries in the multi-play interface.
*   A company profile page to manage a logo that appears on receipts.

Newer requests from the previous session were:
1.  **Real-time Monitoring:** All tickets must be visible to the Super Admin in real-time as they are created.
2.  **Super Admin Impersonation:** The Super Admin must be able to enter a seller's profile and perform actions on their behalf (e.g., make plays, cancel tickets, manage profile).
3.  **Unrestricted Cancellation:** The Super Admin must be able to cancel any ticket at any time, overriding the standard 5-minute window.
4.  **Automatic Commission Deduction:** Seller commissions should be automatically calculated and deducted in reports.
5.  **High-Risk Alerts:** The system should automatically flag high-value or high-risk bets and alert the Super Admin. The risk threshold should be configurable.
6.  **Ticket Preview:** A feature to view the ticket receipt visually within the app without needing to print it.
7.  **Multi-Lotto for Multi-Play:** The ability to include plays for multiple different lotteries within a single multi-play ticket.
8.  **Lottery Hours Validation:** Prevent users from placing bets for lotteries that are currently closed.
